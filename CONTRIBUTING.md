# Contributing

Thank you for your interest in contributing.

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make your updates and test them locally.
4. Open a pull request with a clear description.

## Suggested branch naming

- `feature/<short-name>`
- `bugfix/<short-name>`

## Commit messages

Use short, descriptive commit messages that explain the change.

## Before you submit

- Check that `README.md`, `LICENSE`, and project files are present.
- Make sure `simple-interest.sh` runs as expected.
